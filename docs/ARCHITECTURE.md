# Архитектура

Как устроен код сейчас — см. README. Ниже история и планы.

## Назначение

Библиотека `mathlib` должна была закрыть потребность кафедры в «маленькой
библиотеке математики для лабораторных работ». Изначально предполагалась
объектно-ориентированная модель с классами `Calculator`, `Accumulator` и
`Statistics`, чтобы можно было переиспользовать код в курсе ООП.

## Слои

1. `core` - базовая арифметика, класс `Calculator`
2. `stats` - среднее, медиана, дисперсия, класс `Statistics`
3. `cli` - консольный интерфейс поверх `core`

## Интерфейс `Calculator`

    Calculator *calc = calculator_new(10);
    calculator_add(calc, 5);
    printf("%d\n", calculator_value(calc));
    calculator_free(calc);

Этого API в коде нет и не будет: от классов отказались в 0.3.0. Остатки той
попытки (`src/Calc.c`, `src/legacy_math.c`) удалены.
